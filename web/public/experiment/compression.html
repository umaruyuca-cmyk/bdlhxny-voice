实验对象与数量口径

压缩用例只使用上下文压缩模块维护的三个版本化长 Session:产品演进与需求决策、上下文引擎排查、数据库与部署。默认上下文实验是 4×1:4 种上下文方式 × 1 种固定原生 Tool Calling 配置(模板 context-strategy-comparison,唯一自变量 = context_strategy,其余条件冻结),共 4 个运行、每格 1 次。

三个数量口径全链路分开:repeat_count(压缩用例每格固定 1)/ max_agent_steps(单次运行内模型判断+工具回传的最大步数,服务端配置)/ 实现编号(统一为原生 Tool Calling 底座一种)。

三个 Session 概览

正在读取长上下文库…

当前输入 = Session 最新一条有效用户消息,只发送一次,不进入历史压缩;其之前的事件构成历史。四种方式经过相同的输入构建、Token 统计与工件冻结;只有「按预算压缩」是本项目算法,完整/最近窗口/一次摘要为对照方法。各 Session 四种方式的压缩前后 Token 明细见长上下文库,本页只维护实验入口,不重复展示第二份数字。
