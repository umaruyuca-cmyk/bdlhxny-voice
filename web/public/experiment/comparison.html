对比用例 · 实验

运行数量口径

一次对比任务自动包含全部三种 Agent 实现(固定 Agent 目录:baseline-tool-calling / langgraph-react / full-system),用户不能只挑表现更好的一种进入正式对比。重复次数只允许 3 或 5:

  • 重复 3 次 → 3 种 Agent × 3 = 9 个运行;
  • 重复 5 次 → 3 种 Agent × 5 = 15 个运行;
  • 其他数值前端不提供、后端拒绝。

max_agent_steps(单次运行最大步数)由服务端配置并写入批次,与重复次数分开保存与显示;执行顺序按重复编号轮换,避免同一种 Agent 总是先运行。
