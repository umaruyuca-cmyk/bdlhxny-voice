数据来源

固定题库的唯一数据来源是 PostgreSQL(case_definitions / case_versions / case_variants),引擎评测与 /lab 题号列表都从数据服务读取。本页不手工维护第二份表格,而是读取已发布批次产物(showcase-data)渲染:哪个用例进入过正式批次、每组表现如何,以发布数据为准;新用例入库并参与批次后会自动出现在下表。

怎么读

每行一题:题号 / 场景 / 问题原文,以及每组在最新已发布批次中的正确数(有效口径)。空白表示该题尚未进入任何已发布批次——不是不存在。场景覆盖通用工具任务(检索、日历、文件、邮件等)、对话与知识、拦截与注入防御、多步对话与长上下文,并包含领域示例(金融研究、组合分析等)。
