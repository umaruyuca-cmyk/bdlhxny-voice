私有运行 API · 数据与运行

端点清单

  • POST /api/v1/login / logout — 所有者会话(连续失败锁定);
  • GET /api/v1/cases — 固定题库(题号/版本/变体);
  • GET /api/v1/experiment-templates — 实验模板清单(目的/唯一自变量/变体/冻结条件/权限与上限);
  • POST /api/v1/template-batches/plan — 模板批次预估(精确运行数与变体 config_hash,不创建运行);
  • POST /api/v1/template-batches — 已退役(410):一次请求隐式展开多个 Agent 运行的路径停止创建任务;仅保留压缩方法对照的「生成上下文工件」(context_only,0 个 Agent 运行)兼容;
  • POST /api/v1/experiment-series — 创建实验组(对比用例带 case_id,压缩对照带 session_id;只保存定义与冻结条件,不运行 Agent);
  • POST /api/v1/experiment-series/{id}/runs — 创建一个且仅一个 Agent 运行(幂等键查重、单活跃运行约束、repeat_index 自动分配);
  • GET /api/v1/experiment-series/{id} 与 GET /api/v1/experiment-series/{id}/runs — 实验组定义、样本积累状态与独立运行记录;
  • GET /api/v1/statistics/batches/{id} 与 GET /api/v1/statistics/experiment-series/{id} — 纯代码统计快照(可重建,不产生任何 LLM 请求);
  • POST /api/v1/context-batches — 发起上下文压缩对照批次(三 Session × 四种上下文方式口径);
  • GET /api/v1/jobs/{id} 与 POST /api/v1/jobs/{id}/cancel — 作业状态与协作取消(幂等);
  • GET /api/v1/batches/{id} / GET /api/v1/runs/{id}/detail — 批次运行列表与单次运行逐步明细;
  • /api/v1/public/* — 匿名受限测试接口(实验页运行入口)。

接口不接受问题正文、系统提示词或工具列表;交互文档端点关闭;公开部署不包含此服务。
