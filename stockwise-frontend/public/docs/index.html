系统概览

用户问题 → Agent（路由判断：普通问答 / 领域分析） → Skill（行情、指标、回测、热度等结构化计算） → 模型（本地解释 / 付费正式研判） → 结论 + 依据 + 风险 + 数据时间
边界：Skill 是确定性的数据和计算层；调用 Skill 不等于调用付费大模型。只有在需要把结构化结果转成正式研判结论时才调用付费模型。
