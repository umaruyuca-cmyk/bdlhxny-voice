# DB 执行记录（execution）

本目录记录**每一次数据库相关变更的执行说明**。结构变更仍改 `postgresql/schema/` 与 `seed/`；这里只写「怎么跑、这次改了什么」。

## 约定

1. **只全量**：目标库为空，或先清空再重建；不用增量 upgrade 脚本。
2. **单账号**：用一个超级管理员（或等价高权限账号）连接并执行。
3. **一次变更一份文件**：文件名 `YYYYMMDD_简短说明.md`，按日期排序；**不要改写旧文件**，只追加新文件。
4. **最新有效基线**：以本目录中日期最新的一份为准；若某次只需「按最新基线整库重跑」，在新文件里写清即可。

## 新开一次 DB 更新时

1. 修改 `postgresql/schema/*.sql` 和/或 `postgresql/seed/*.sql`（以及必要时 `bootstrap.sql`）。
2. 在本目录**新增**一份 `YYYYMMDD_....md`，写明：
   - 变更摘要
   - 是否要求清空重建
   - 完整执行顺序（可复制上一份基线并标注差异）
   - 验收要点
3. 更新上一级 [README.md](../README.md) 中「当前基线」链接指向最新文件。
