## 验收要点

- `SELECT user_id, risk_tolerance, profile_version, confirmed_at FROM public.user_configs WHERE user_id=1;`
  → 返回 1 行，`risk_tolerance='moderate'`，`profile_version=1`，`confirmed_at` 非空。
- `SELECT code, name, shares, avg_cost, exchange, active FROM public.portfolio_positions WHERE user_id=1 ORDER BY code;`
  → 返回 4 行，含 `300750 宁德时代`，全部 `active=TRUE`。
- `SELECT count(*) FROM public.financial_profile_confirmations WHERE user_id=1;` → 1。
- Java 数据面 `GET /internal/v1/financial-profile?userId=1` 返回稳健型画像；`GET /internal/v1/portfolio/positions?userId=1` 返回 4 只持仓（具体路径以 Java Controller 为准）。
- `cd sentinel-data && mvn -B -ntp test` 不劣化（基线 40 tests 全绿）。
- 重跑 `demo_sentinel.sql` 不报唯一冲突（DELETE 守卫生效），持仓行数仍为 4。
