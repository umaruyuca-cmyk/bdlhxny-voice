# 20260817 — 空库全量初始化

## 变更摘要

- 建立当前 Runtime / Registry（八表）/ Memory / 金融用户资料全量结构
- Registry 业务种子（无 plugin-contract-probe；无旧资格/快路径/主题表）
- 运维约定：单超管、只全量、无 upgrades 目录

## 前置条件

- PostgreSQL 目标库已创建且**为空**（无业务表），或已整库清空
- 使用一个超级管理员账号连接

## 执行顺序

```text
1. postgresql/bootstrap.sql
   变量：runtime_data_password、memory_service_password

2. postgresql/schema/platform_contract.sql
3. postgresql/schema/runtime_core.sql
4. postgresql/schema/task_messaging.sql
5. postgresql/schema/notifications.sql
6. postgresql/schema/run_projection.sql
7. postgresql/schema/registry.sql
8. postgresql/schema/financial_user_data.sql
9. postgresql/schema/memory_service.sql

10. postgresql/seed/registry.sql
```

可选（独立 MySQL 认证库，与本 PG 库无关）：

```text
mysql/user_schema.sql
```

## 验收

- 存在 schema：`business`、`runtime`、`registry`、`memory`
- `registry` 仅有最终八张目录表，且 seed 后 operation/capability/skill 有数据
- 存在 `public.user_configs`、`public.portfolio_positions` 等
- Java Data Plane `/internal/v1/registry/snapshot` 可读
