# Agent 对照评测与证据展示

## 1. 目标

评测必须同时证明三件事：

1. Agent 能完成固定任务；
2. 工程限制确实减少了工具、权限、数字和合规错误；
3. 上下文压缩减少了 token 和时长，但没有丢失关键事实。

公开展示不只给出结论，还要提供实验设置、全量分布和单次运行记录。

## 2. 两类实验分开运行

### 2.1 Agent 实现方式对照

在相同固定用例、数据快照、模型和上下文策略下比较：

- 裸 tool calling（baseline）；
- 完整工程模式（full-system）。

该对照**同时改变循环、上下文组织、工具装载和治理，是整体实现方案诊断，不是严格单变量实验**，不能用来证明某单项能力单独有效；LangGraph ReAct 已并入 native 底座，仅保留历史只读兼容。新正式单变量实验（治理开关、工具提供方式 all/search、温度、步数等）以实验模板定义，唯一自变量之外的条件全部冻结（`RunConfig` + `config_hash`），请求参数与实际生效参数分别记录。该实验回答工具选择、权限、拦截、数字依据和运行轮次问题。

### 2.2 上下文处理方式对照

固定 Agent 实现方式，比较：

- 完整上下文；
- 最近 N 条截断；
- 一次性 LLM 摘要；
- 按预算选择和压缩。

该实验回答 token、关键事实保留、任务成功率和构建时长问题。

不能在同一张表中同时改变 Agent 实现和上下文策略后，把差异归因给其中一个因素。

## 3. 公平运行条件

同一对照批次必须共享：

- 固定用例版本；
- 数据快照和模拟工具返回；
- 模型版本、温度和最大输出；
- 工具目录版本；
- Prompt 版本；
- 超时和重试策略；
- 评测器版本；
- 重复次数。

运行顺序应交错或随机化，避免先运行的一组总是遇到更好的服务状态。每组正式结果初始至少重复 5 次；调试运行和单次现场演示不能替代正式报告。

## 4. 用例覆盖

题库不以数量为唯一目标，而要覆盖以下维度。

### 4.1 任务类型

- 闲聊和金融知识；
- 实时行情和历史行情；
- 新闻和行业信息；
- 估值研究；
- 持仓和组合诊断；
- 风险匹配筛查；
- 事件解读；
- 交易和越权请求拦截。

### 4.2 工具路径

- 不需要工具；
- 单工具；
- 多工具串行；
- 多工具并行；
- 工具返回空数据；
- 工具超时；
- 部分工具成功；
- 参数错误；
- 模型调用不存在的工具；
- 数据过期或来源冲突。

### 4.3 上下文长度和结构

- 4K、8K、16K、32K、64K 候选上下文；
- 关键事实位于开头、中间和末尾；
- 大量重复信息；
- 大量无关记忆；
- 新旧数据冲突；
- 同一个数字对应不同日期；
- 长日志中只有一个关键错误；
- 长新闻中只有一条与持仓相关的信息；
- 多步用例中的指代和状态延续。

### 4.4 安全和权限

- 问题中的提示注入；
- 新闻或工具结果中的间接提示注入；
- 游客读取持仓或记忆；
- 交易操作请求；
- 要求泄漏系统提示；
- 伪造引用；
- 诱导给出确定的适当性结论。

### 4.5 基础设施故障

- LLM 429、余额不足和超时；
- 工具服务不可用；
- 评测器不可用；
- 工件写入失败；
- 缓存失效；
- 运行取消；
- 重复提交；
- 事件乱序或重复。

## 5. 测试分层

| 层级 | 内容 | 运行时机 |
|---|---|---|
| 单元测试 | 预算、选择、权限、参数、hash、脱敏 | 每次提交 |
| 确定性回归 | 固定模型替身和模拟工具数据 | 每次提交 |
| 压力评测 | 长上下文、冲突、注入、故障 | 合并前或定时运行 |
| 真实模型评测 | 实验模板批次（唯一自变量）、4×1 上下文实验、多次重复 | 发布正式报告前 |
| 演示门禁 | 代表性用例、静态工件、录屏 | 面试或发布前 |

## 6. 运行有效性

### 6.1 有效运行

同时满足以下条件才进入能力统计：

- 模型服务正常完成；
- 数据快照可读；
- 工具执行环境满足用例要求；
- 运行工件完整写入；
- 评测器完成或确定性检查完成；
- 没有 429、余额不足、服务不可用等外部故障。

### 6.2 无效运行

无效运行保留在批次中，但不计入成功率。报告单独显示：

- 总运行数；
- 有效运行数；
- 无效运行数；
- 按原因分组的无效运行；
- 是否达到最小有效样本数。

如果任一对照组未达到设定的有效重复次数，整个批次不能成为公开首页的“最新正式结果”。

## 7. 指标定义

### 7.1 任务与工具

| 指标 | 定义 |
|---|---|
| 任务成功率 | 满足该用例全部必要检查的有效运行比例 |
| 工具选择准确率 | 实际成功工具集合与期望工具集合一致的比例 |
| 不存在工具调用率 | 调用了当次工具目录中不存在的名称的比例 |
| 权限泄漏率 | 未授权运行成功访问受限工具或数据的比例 |
| 平均工具调用数 | 每个有效运行的工具调用数 |
| 平均模型轮次 | 每个有效运行的模型调用轮次 |

### 7.2 事实和安全

| 指标 | 定义 |
|---|---|
| 数字无依据率 | 最终答案中的事实性数字无法在工具结果或数据快照中找到的比例 |
| 引用完整率 | 需要来源的结论带有有效引用的比例 |
| 关键约束保留率 | 压缩后仍保留全部强制约束的比例 |
| 关键事实召回率 | 评测标注的关键事实进入工作上下文的比例 |
| 错误事实进入率 | 无来源或冲突信息被当成确定事实的比例 |
| 提示注入成功率 | 不可信文本改变系统指令或触发越权行为的比例 |
| 合规违规率 | 违反交易边界或适合度口径的比例 |

### 7.3 Token、时长和成本

| 指标 | 定义 |
|---|---|
| 原始上下文 token | 全部候选条目的 token 总数 |
| 工作上下文 token | 实际发送给模型的上下文 token |
| token 减少比例 | `(原始 - 工作) / 原始` |
| 上下文构建时长 | 收集、选择、摘要和校验的总时长 |
| 首次输出时长 | 从创建运行到第一个有效输出的时长 |
| 总运行时长 | 从创建运行到工件写入完成的时长 |
| 模型调用成本 | 输入和输出 token 按模型价格计算的成本 |
| 压缩成本 | 摘要或提取额外消耗的模型成本 |
| 净节省 | 未压缩成本减去压缩后总成本 |

时长报告至少展示 p50、p95 和最大值。成本必须包含上下文抽取和摘要，不能只统计主 Agent。

## 8. 初始质量门槛

以下指标是发布正式报告的硬门槛：

- 强制约束保留率为 100%；
- 公开敏感信息泄漏为 0；
- 交易工具实际执行次数为 0；
- 无效运行不进入能力指标；
- 运行工件和公开工件 hash 校验通过率为 100%；
- 每个正式对照组达到规定的有效重复次数。

上下文策略是否可作为默认方案，还需要满足：

- 相比完整上下文，任务成功率没有明显下降；
- 长上下文用例的关键事实召回率达到预设标准；
- token 或总成本有稳定下降；
- 上下文构建 p95 时长不成为主要瓶颈。

具体数值在首轮无污染基准完成后写入评测配置，不在设计文档中猜测。

## 10. 批次报告

批次报告至少包含：

- 实验目的和唯一变量；
- 固定条件和版本；
- 每组有效、无效和失败数量；
- 总表和分场景表；
- 获胜、退化、平局和双方失败数量；
- 全部案例链接；
- 无效运行原因；
- 时长、token 和成本分布；
- 已知限制。

不能只自动选择“基线失败、完整模式成功”的案例。首页可以突出代表案例，但必须提供全量入口和筛选规则。

## 11. 公开展示

### 11.1 首页 `/showcase`

- 一句话说明项目不是公开聊天产品；
- 展示固定用例到运行工件的流程；
- 显示最新有效批次，而不是最新生成批次；
- 显示任务成功、约束保留、token、p95 时长和无效运行数量；
- 明确数据生成时间、Git commit 和模型。

### 11.2 结果页 `/showcase/results`

- 分开显示 Agent 实现方式对照和上下文策略对照；
- 支持按场景、用例、组别和有效性筛选；
- 同时显示胜、负、平和无效；
- 指标定义可就地展开。

### 11.3 运行页 `/showcase/runs`

详情按以下顺序展示：

```text
固定输入和受控变量
→ 原始上下文与压缩结果
→ 当次可见工具
→ 模型决策
→ 代码允许或拒绝
→ 工具结果及来源
→ 输出检查
→ 最终结果和评测
→ 时长、token 和成本
```

### 11.4 上下文页 `/showcase/context`

- 比较四种上下文策略；
- 显示原始 token、工作 token、压缩成本和净节省；
- 显示强制项和关键事实是否保留；
- 展示至少一个压缩成功案例和一个压缩退化案例；
- 不公开被省略内容的敏感原文。

## 12. 发布校验

发布前自动检查：

- 批次满足最小有效样本数；
- 没有真实用户持仓、记忆、手机号、邮箱、密钥或完整系统提示；
- 所有公开引用都能解析；
- 每个公开工件 hash 与索引一致；
- 报告没有把 0% 到 0% 描述为改善；
- 报告没有把基础设施失败当成 Agent 失败；
- 页面使用机器数据渲染数字，不手写最新结果。

长上下文页面的固定数据、正反例和首批展示案例见 [固定用例与网页展示.md](../showcase/固定用例与网页展示.md)。
