# 前后端对接文档(新信息架构 × engine API)

> 状态:对接契约 v1,与代码核对过(2026-08-26)
> 前端:`web/public/`(静态站,原型见 `docs/design/前端页面原型.html`)
> 后端:`engine/src/bdlh_runtime/run_api.py`(FastAPI,默认与 data 服务分离)
> 口径依据:`docs/prompts/11-混合路线实施清单.md` D2/D3、`docs/design/前端信息架构与页面设计.md`

---

## 1. 总览

```text
浏览器(静态页) ──同源──► engine run_api(FastAPI) ──内部──► data 服务(落库/读取批次与运行)
                  │                │
                  │                └─ 匿名身份:HttpOnly Cookie(原始值不出浏览器,任务只存哈希)
                  └─ 静态数据:/showcase-data/*.json(工具目录、用例投影、发布索引)
```

两类身份,两套端点前缀相同但权限不同:

| 身份 | 标识方式 | 可用端点 |
| --- | --- | --- |
| 匿名访客 | `ANON_COOKIE`(HttpOnly, SameSite=Lax,首次请求自动签发;服务端只存 `sha256(token)`) | `/api/v1/public/*` |
| 登录所有者 | `POST /api/v1/login` 获取会话(Bearer/Cookie,`require_login` 依赖) | `/api/v1/*`(含 public 全部能力) |

硬性安全约定(前端必须遵守):

- 客户端**只能提交固定编号与白名单配置字段**;`message / prompt / system_prompt / tool_schema / mock_result / model_base_url / api_key` 等字段会被后端直接拒绝(400)。
- 匿名与所有者都**不能上传任意变体数组**;`variant_labels` 只能是模板既有变体的子集。
- 匿名结果不可发布,不进公告;公告数据只来自发布快照(见 §7)。

## 3. 模板中心

### 3.1 匿名:`GET /api/v1/public/test-options`

一次拉齐发起页所需的全部只读选项(会顺带签发匿名 Cookie)。

```jsonc
{
  "sessions": [/* 版本化长对话:session_id, title, token 规模 */],
  "comparison_cases": [/* 公开用例投影:case_id, case_version, 标题 */],
  "templates": { /* 模板注册表(匿名视角,已过滤 owner-only) */ },
  "tool_exclusion_presets": [/* 工具排除预设(编号/说明/排除数量;tool-availability-degradation 档位下拉) */],
  "fixed_conditions": {
    "test_types": ["COMPRESSION_CASE", "COMPARISON_CASE"],
    "native_agent_mode_id": "native-tool-calling",
    "repeat_options": [1, 3, 5],
    "run_counts": { "comparison_repeat_3": 0, "compression_native_matrix": 0 }
  },
  "quota": { /* 匿名配额:并发、日上限、repeat 上限等 */ }
}
```

### 3.2 所有者:`GET /api/v1/experiment-templates`(需登录)

返回完整注册表 `template_registry_payload(role=owner)`,含 owner-only 模板与高级设置白名单。模板对象字段:

| 字段 | 说明 | 前端用途 |
| --- | --- | --- |
| `template_id` / `version` | 模板标识 | 技术口径行 |
| `purpose` | 实验目的(书面语) | 卡片说明 |
| `classification` | `formal` / `cross-diagnostic` / `legacy-diagnostic` | 徽章:正式单变量/专项交叉/历史诊断 |
| `independent_variable` + `independent_variable_label` | 唯一自变量(技术名 + 展示名) | "受控变量"行;展示用 label,技术行用原名 |
| `variants[]` | 变体(label + 覆盖值) | 变体列表;`variant_labels` 只能从这里选 |
| `frozen_conditions` | RunConfig 基线快照 | 左栏"冻结条件" |
| `allowed_test_types` | `COMPARISON_CASE` / `COMPRESSION_CASE` | 决定渲染"考题"还是"长对话"选择器 |
| `anonymous_allowed` / `owner_allowed` | 权限 | 卡片置灰逻辑 |
| `repeat_count_range` / `max_runs_per_batch` | 重复次数范围、批上限 | 重复次数下拉与校验 |
| `advanced_allowed_paths` | 高级字段白名单(如 `limits.max_tool_calls`) | 高级设置区仅所有者渲染 |
| `allow_context_only` | 允许只生成输入 | 上下文模板的"仅生成工件"开关 |
| `requires_capability` | 需要模型能力(如温度) | 不满足时禁用发起 |
| `run_count_formula` | 运行数公式说明 | 预估条展示 |

## 4. 发起实验(预估 → 提交)

### 4.1 预估:`POST /api/v1/template-batches/plan`(需登录)

请求(与提交同构,`extra="forbid"`,多字段直接 400):

```jsonc
{
  "template_id": "governance-on-off",
  "repeat_count": 3,              // 1..20,且须落在 repeat_count_range
  "preset_id": null,              // 仅 tool-availability-degradation 使用
  "variant_labels": null,         // 模板既有变体子集;不允许自定义
  "context_only": false,          // 仅 allow_context_only 模板
  "advanced": { "limits": { "max_tool_calls": 6 } }  // 键须在 advanced_allowed_paths 内
}
```

响应(plan 不创建任何运行):

| 字段 | 说明 |
| --- | --- |
| `run_count` | **精确运行数**,前端预估条必须原样展示("N 组 × M 次 = run_count") |
| `fixed_conditions` + `fixed_conditions_hash` | 批次冻结条件与哈希 |
| `runs[]` | 每次运行的 `variant_label / repeat_index / config_hash / run_config(含生效参数)` |
| `classification` / `template_version` / `independent_variable` | 口径展示 |

前端流程:**任何配置变更 → 重新 plan → 展示 run_count → 用户确认后才允许提交**;plan 失败(400)时把 `detail` 文案展示在提交按钮旁(超上限、能力不满足、冻结字段被覆盖等)。

### 4.2 所有者提交:`POST /api/v1/template-batches`(需登录)

请求 = plan 请求 + `case_id`。服务端限制:`classification` 必须为 `formal`;`context_only=true` 被拒(仅 plan 接受);上下文类模板不走此入口(走 §5)。并发约束:全局仅一个批次槽,冲突返回 **429**(前端提示"已有批次在运行")。

响应:

```jsonc
{ "job_id": "ab12cd34ef56", "batch_id": "...", "template_id": "...", "classification": "formal", "formal": "true" }
```

随后轮询 `GET /api/v1/jobs/{job_id}`(进度 `progress.done/total/current`),`POST /api/v1/jobs/{job_id}/cancel` 取消。

### 4.3 匿名提交:`POST /api/v1/public/test-jobs`

请求只接受固定编号与白名单字段(`case_id` / `session_id` / `test_type` / `agent_mode_id` / `repeat_count` 等,具体由 `_public_service.create_job` 校验)。响应:

```jsonc
{ "job_id": "...", "status": "queued", "unit_count": 6, "publishable": false, "custom_conditions": false }
```

`publishable=false` 时前端必须展示"个人测试 · 非正式结果"标记。

## 6. 批次与结果

### 6.1 匿名

| 端点 | 用途 | 备注 |
| --- | --- | --- |
| `GET /api/v1/public/test-jobs` | 我的任务列表(近 20 条:`status / completed_units / total_units`) | 5s 轮询;只返回当前 Cookie 身份的任务 |
| `GET /api/v1/public/test-jobs/{job_id}` | 任务状态与摘要(`public_view()`) | 他人任务一律 **404**(不泄露存在性) |
| `GET /api/v1/public/test-jobs/{job_id}/results` | 结果与单元明细(已脱敏:不含 gold、内部提示、未脱敏工具返回) | 批次详情页数据源 |
| `POST /api/v1/public/test-jobs/{job_id}/cancel` | 取消(仅阻止未开始单元) | 返回 `cancelled_units` |

### 6.2 所有者

| 端点 | 用途 |
| --- | --- |
| `GET /api/v1/batches?limit&cursor` | 批次列表(新到旧分页):`id / template_id / template_classification / independent_variable / repeat_count / variant_count / run_count / status / created_at`;历史批次模板字段为 null |
| `GET /api/v1/batches/{batch_id}` | 批次口径卡数据:`fixed_conditions(含 fixed_conditions_hash)`、模板标识、状态;`runs[]` 含逐运行 `modelConfig`(模板标识/config_hash/perRunConfig 快照) |
| `GET /api/v1/runs/{run_id}/detail` | 单次运行下钻:事件流、模型/工具/护栏明细、测量、工件登记 |

每次模板运行的 `modelConfig`(JSONB)已包含:`templateId / templateVersion / variantLabel / repeatIndex / configHash / perRunConfig(请求+生效参数)/ toolSchemaHash / eligibleCatalogHash / fixtureSetId`——批次详情页"请求 vs 生效参数对照表"与"工具可见性"行直接取自这里,**生效值为 null 必须展示原因**(见 `unsupported_reasons`)。

### 6.3 前端渲染口径(对应 D3)

1. 首屏顺序:目的 → 受控变量与变体 → 冻结条件 → 技术口径行(`config_hash`、Schema 哈希、可见工具数与排除项)→ 请求/生效参数表 → 按自变量分组的结果矩阵。
2. 分组键:`variantLabel`;**不再按 `agent_mode` 分组**(旧字段仅历史批次展示)。
3. `classification=legacy-diagnostic` → 置顶"非严格单变量"警告条;匿名结果 → "个人测试 · 非正式结果"标记。
4. 执行前失败的批次(固定条件被覆盖等)展示失败原因,不渲染空矩阵。

## 9. 前端通用约定

1. **轮询**:任务列表/详情 5s 轮询;`status` 进入 `done/error/cancelled` 后停止。断页不中断后台任务(后端线程/队列执行)。
2. **错误码**:400(校验失败,`detail` 为普通话原因,直接展示)/ 404(匿名任务不存在或无权)/ 429(批次槽占用,提示稍后)/ 503(data 服务不可用,提示系统异常)。
3. **文案分层**:`independent_variable_label`、`purpose` 直接用于第一层展示;`template_id`、变量原名、哈希只在技术口径行展示。前端不自造指标名,`result_metrics` 由模板返回。
4. **哈希展示**:一律 8 位短显 + 悬停全量 + 点击复制。
5. **缓存**:模板与选项接口 `cache: no-store`;静态资产 JSON 可走 HTTP 缓存。
6. **角色视图**:同一页面按身份渲染;匿名不渲染高级设置(DOM 级移除),owner-only 模板卡片置灰并标"需登录"。
