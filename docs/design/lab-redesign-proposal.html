DESIGN PROPOSAL · 运行台 /lab/ 重设计

主题收敛：从「自带一套灰蓝」回归全站文档风

现状问题：运行台内联了一套独立样式（深灰蓝按钮 #1f2d3d、独立边框/状态色），与全站 docs.css 的设计令牌（accent #2563eb、白底文档风）脱节，视觉上像另一个产品。本方案不改任何交互与接口，只做主题收敛与信息架构重组。

1主题令牌同源全部颜色/圆角/阴影直接复用 docs.css 变量；按钮、徽章、表格换成全站组件（.btn / .tag / .cat-table 同规格）。
2三段式信息架构顶部「状态概览条」（模型绑定·作业·队列）→ 中部「发起区」（三张实验入口卡）→ 底部「结果区」（进度 + 批次明细）。
3发起入口分级标准对照为唯一主按钮；压缩对照 / 联动对照降为次级卡；一键发起并入主卡，不再单独一条浅色横幅。
4表单降噪token 上限、fixture、top_k 等低频参数收进「高级选项」折叠区；工具勾选墙限高滚动，不再撑满首屏。
5反馈升级作业状态从纯文字轮询改为进度条 + 状态徽章；运行详情从长 dl 列表改为卡片 + 工具调用 chip 轨迹。
6绑定生命周期闭环模型接入补齐「解绑」操作：危险样式按钮 + 二次确认；解绑后卡片回落到「未绑定 · 用服务端环境配置」状态，密钥随绑定一并清除。
