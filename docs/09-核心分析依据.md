# StockWise 核心分析依据

> 文档版本：1.0  
> 对应 Skill：`@stockwise/stock-analysis-skill@1.1.1`  
> 方法论标识：`stockwise-objective-analysis`  
> 方法论版本：`1.0.0`  
> 更新时间：2026-07-29

## 1. 文档目的

本文面向接入 StockWise 分析服务的 Agent 开发者、审核人员和运维人员，说明分析结论从哪里产生、哪些内容可以复算、哪些内容属于风险政策或启发式，以及调用方应如何解释结果。

本服务是确定性分析与风控引擎，不是收益预测模型，也不是持牌投资顾问。相同输入、相同数据时间和相同方法论版本应得到相同结果。大模型只允许解释结构化结果，不得改写指标、阈值、数据时效门禁和风险拦截。

Skill 内部完整方法论真源位于：

```text
skills/stock-analysis-skill/references/methodology.md
```

本文是供外部调用方阅读的稳定版本。公式、阈值或门禁含义发生变化时，必须同步升级 `methodology.version`。

## 2. 分析链路

```text
请求参数
  → 资产类型识别
  → 结构化行情/净值拉取
  → 北京时间与交易日校验
  → 确定性指标计算
  → 数据质量和风险硬门禁
  → 评分、排序或资金配置
  → methodology + decisionBasis
  → 固定 JSON
  → 大模型或业务系统解释
```

大模型不参与行情计算、技术指标计算、回测、排名、风险门禁和仓位计算。

## 3. 证据等级

每条方法规则都必须声明证据等级：

| 等级 | 含义 | 当前示例 |
|---|---|---|
| `deterministic` | 使用固定公式，可由相同输入复算 | MA、MACD、RSI、收益率、波动率、盈亏、费用 |
| `research_based` | 方法方向有公开研究支持，具体参数由本项目实现 | 动量排序、趋势过滤、波动率目标 |
| `risk_policy` | 为降低错误交易风险设置的工程硬门禁 | 数据过期阻断、追高禁止、现金底线、仓位上限 |
| `heuristic` | 尚未完成独立样本外校准的启发式 | 单股100分制、板块热度权重、补仓梯度 |

`heuristic` 不得被解释为统计胜率、预期收益或上涨概率。历史回测也不得被描述为未来收益保证。

## 4. 数据来源与时效

当前数据来源：

- A股和ETF行情：东方财富，失败时降级新浪。
- A股和ETF K线：东方财富，失败时降级腾讯。
- 场外基金和QDII净值：东方财富基金历史净值。
- 行业和概念板块：东方财富结构化板块行情；列表中的当日、5日、资金流和换手字段用于初筛，最多对10个候选板块受控补拉K线核验20日表现。不得把资金流字段猜测成20日涨跌。
- 海外指数：腾讯结构化行情。
- 新闻、公告和宏观背景：可以使用SearXNG，但搜索摘要不得替代结构化行情、K线、净值或资金流事实。
- 时间、交易日和“当日”统一使用 `Asia/Shanghai`。

上游请求使用有限连接池和分场景并发限制，只对网络中断、限流及临时服务端错误执行带抖动的指数退避。市场、板块和海外背景可以带警告降级；必需持仓或量化基准缺少价格/K线时必须终止方向性分析。

方向性分析必须先通过 `DATA-FRESH-001`：

- 盘中行情年龄不超过120秒。
- 必须存在北京时间当日K线。
- 行情时间和最新K线日期必须一致。
- 缺失时间戳、数据源失败或K线不同步时，设置 `allowsDirectionalSignal=false`。
- 场外基金只按最新公布净值分析，不得描述成实时价格。

只要时效门禁失败，调用方必须强制观望，不能根据后续评分生成买入、卖出或加仓结论。

## 5. 单标的分析

### 5.1 确定性技术指标

- MA5/10/20/60：相应窗口收盘价的算术平均值。
- MACD：EMA(12)减EMA(26)，Signal使用9期EMA。
- RSI6/12/24：按涨跌变化的平滑结果计算。
- 乖离率：`(当前价格 - MA) / MA × 100%`。
- 量比：当前成交量与比较窗口平均成交量之比。
- 支撑与压力：最近20日高低点及关键均线。

对应 Rule ID：`TECH-IND-001`。

### 5.2 技术评分

单标的100分制由以下维度构成：

| 维度 | 分值 |
|---|---:|
| 趋势 | 30 |
| MA5乖离 | 20 |
| MACD | 15 |
| 量价 | 15 |
| RSI | 10 |
| 支撑 | 10 |

信号分界为72、62、42、28，但最终结果仍受均线排列、基本面否决、数据时效和追高硬门禁覆盖。

对应 Rule ID：`SCORE-HEURISTIC-001`。该评分只用于规则化排序，尚未完成独立样本外校准。

### 5.3 追高硬门禁

任一条件触发即禁止新增买入或加仓：

- RSI6大于75。
- MA5乖离大于4%。
- MA20乖离大于8%。
- 接近20日新高且量比小于0.8。
- 单日涨幅大于5%且量比大于2.5。
- MA60乖离大于30%。

对应 Rule ID：`CHASE-HARD-001`。它是风险政策，不代表满足条件后必然下跌。

## 6. 组合分析

组合分析使用真实用户持仓、现金和月度预算，不允许回退到示例持仓。

当前主要规则：

- 当前权重等于持仓市值除以持仓市值与现金之和。
- 单板块权重达到35%时提示集中风险。
- 现金保留比例不得低于15%。
- 数据质量不足、追高硬警告、空头均线排列或超过仓位上限时禁止加仓。
- 可部署预算按目标权重、技术分数、欠配程度和回踩条件分配。
- 建议金额过低时保留现金，避免最低佣金侵蚀。

对应 Rule ID：

- `PORT-RISK-001`
- `ALLOC-HEURISTIC-001`

当前没有完整协方差矩阵、相关性聚类、VaR/CVaR和压力测试，因此不能称为机构级组合优化。

## 7. ETF量化轮动与回测

当前模型：

- 使用20/60/120日动量。
- 横截面Z分数权重为40%/35%/25%。
- 价格必须高于MA60。
- 入选资产按20日年化波动率倒数配置。
- 单品种上限35%。
- 组合目标年化波动率12%。
- 基准跌破MA200或20日波动率超过近252日样本80分位时转为现金。
- 默认每5个共同交易日调仓。
- 默认单边成本率0.03%。
- 调仓信号只使用前一交易日及更早数据。

对应 Rule ID：

- `QUANT-MOM-001`
- `QUANT-VOL-001`
- `BACKTEST-NOFUTURE-001`

动量和波动率管理的方法方向有公开研究支持，但当前窗口、候选ETF池和具体阈值仍是本项目实现，不能因此直接视为统计有效。

研究参考：

- Time Series Momentum：<https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum>
- Volatility Managed Portfolios：<https://www.nber.org/papers/w22208>
- Do Industries Explain Momentum?：<https://www.aqr.com/Insights/Research/Journal-Article/Do-Industries-Explain-Momentum>

## 8. 板块热度

板块热度 `sector-heat-v2` 先在同类板块、同一快照内转换为 0–100 横截面分位，再使用固定权重：

```text
0.35 × 当日涨跌分位
+ 0.25 × 5日涨跌分位
+ 0.15 × 20日涨跌分位
+ 0.15 × 主力净流入分位
+ 0.10 × 换手率分位
```

对应 Rule ID：`SECTOR-HEAT-001`。

缺失分项不补零，也不使用 5 日涨跌冒充 20 日涨跌，而是按真实可用权重重标并降低 `heatScoreQuality`。JSON 必须公开每项原始值、标准化值、权重、有效权重、贡献和样本量。该分数只用于相对排名和背离观察，不代表后续上涨概率。供应商“主力资金”字段也不等同于交易所逐笔资金审计。

外围新闻、搜索讨论和“大众关注代理”与行情热度分离。它们由 Java 编排层基于固定 `SearchResult` 计算 `attentionHeat`，不得混入 `SECTOR-HEAT-001`，也不得解释成真实搜索人数、平台互动量或特定人群数量。

## 9. 基本面能力边界

当前基本面只覆盖数据源可获得的PE、PB、市值和少量红旗规则，尚未完整覆盖：

- 财报质量和现金流。
- 盈利预测与预测修正。
- 行业估值分位。
- 公司治理。
- 公告、监管和重大事件核验。

因此基本面目前只能作为技术信号的风险修正，不能独立形成长期价值结论。缺少数据不等于基本面良好。

## 11. Rule ID追溯表

| Rule ID | 证据等级 | 作用 |
|---|---|---|
| `DATA-FRESH-001` | risk_policy | 数据过期或不同步时阻断方向结论 |
| `TECH-IND-001` | deterministic | 固定公式计算技术指标 |
| `SCORE-HEURISTIC-001` | heuristic | 单标的规则化评分 |
| `CHASE-HARD-001` | risk_policy | 过热、严重乖离或量价背离时禁止新增 |
| `PORT-RISK-001` | risk_policy | 仓位、集中度、现金、费用和T+1约束 |
| `ALLOC-HEURISTIC-001` | heuristic | 可部署预算分配 |
| `QUANT-MOM-001` | research_based | ETF多周期动量排序 |
| `QUANT-VOL-001` | research_based | 逆波动率和目标波动率配置 |
| `BACKTEST-NOFUTURE-001` | deterministic | 无未来函数回测与成本扣除 |
| `SECTOR-HEAT-001` | heuristic | 板块热度相对排序 |

## 12. 当前专业程度与后续升级

当前已经具备：

- 数据时效硬门禁。
- 确定性公式和固定JSON。
- 方法论版本和Rule ID。
- 观测值、门禁结果和限制追溯。
- 无未来函数的基础回测。
- 大模型不能覆盖风险门禁。

继续升级至少需要：

1. 固定、可复现的数据快照和基准。
2. 训练期、验证期和独立样本外测试期。
3. 胜率、盈亏比、覆盖率、成本后收益、回撤和参数敏感性。
4. 幸存者偏差、涨跌停、停牌、冲击成本和跟踪误差测试。
5. 组合相关性、VaR/CVaR和压力测试。
6. 完整财报、公告和事件研究。
