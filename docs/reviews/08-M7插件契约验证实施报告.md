# M7 插件契约验证实施报告

> 实施日期：2026-08-12  
> 状态：`DEVELOPMENT_COMPLETE / CONTRACT_VALIDATED / NOT_A_PRODUCT_FEATURE`  
> 验证形态：S2 最小第二 Domain `plugin_probe`

## 1. 验证目标

用新增第二 Domain 证明 ADR-010 的现有插件契约支持“只写领域插件、内核不动”，并且
不会复制 Capability Registry、Toolset、Observation、Guardrail、DomainBudget、审计码
或持久化基础设施。

本阶段不承诺业务价值，不增加金融、知识、自动化或多 Agent 产品能力。

## 2. 交付内容

- 新增 `domains/plugin_probe/`：严格 `PluginProbeRequest / Outcome / Result`、
  `PluginProbeRuntime`、编译期 `SkillManifest / DomainDescriptor`；
- 第二 Domain 状态为 `EXPERIMENTAL`，唯一 intent 为 `CONTRACT_PROBE`；
- 在唯一 Capability Registry 中注册本地只读
  `plugin_probe.run_contract_check`，并由唯一 Toolset 派生视图提供
  `plugin_probe_compute`；未建立第二 Registry 或第二 Toolset 实现；
- 应用装配通过现有 `DomainRegistry` 注册 Runtime/Descriptor，并使用现有
  `validate_descriptor_against_registry` fail-fast；
- Runtime 通过现有 `DomainDispatcher` 调度，使用既有 `DomainRequest / DomainOutcome /
  DomainBudget / Observation`；
- 现有 Plan/Action Guardrail 可直接允许或阻断探针请求；
- 探针只执行确定性本地校验，工具调用预算和模型调用预算必须为零；
- 应用中的 Cognitive `enabled_domains` 保持仅 `finance`，探针没有聊天、HTTP 或用户入口。

## 3. 退出门槛证明

| 单一真源 | M7 行为 |
|---|---|
| Capability Registry | 在现有 `build_default_capability_registry` 增量注册一项，只注入同一对象 |
| Toolset | 只增加 enum/描述，继续由 `ToolsetRegistry` 动态派生 |
| Observation | 直接实例化通用 `contracts.observation.Observation` |
| Guardrail | 直接通过现有 DefaultPlan/ActionGuardrail，未定义插件 Guardrail |
| DomainBudget | 直接使用通用 `domains.contracts.DomainBudget` |
| Dispatcher/Registry | 只调用现有注册与调度 API，未修改通用实现 |
| 审计 | 使用 Manifest 声明的稳定 `PLUGIN_PROBE_EXECUTED`，未另建审计系统 |
| 持久化/幂等 | 只声明 `request_id + probe_ref`；无写副作用、无插件 Store |

架构测试静态禁止探针声明 `CapabilityRegistry / ToolsetRegistry / DomainBudget /
Observation / Guardrail / TaskStore / RunRegistry` 同名基础类，并禁止依赖 Finance、供应商
Adapter、Memory 或 LangGraph。

## 4. 边界

- 不开放用户请求；
- 不访问网络、LLM、数据库、Memory 或用户金融事实；
- 不新增真实业务 KPI、外部供应商或通知；
- 不启用 M3 Suitability；
- 不进入 ADR-012 的 S3/S4 多角色或多 Agent；
- M0/M5/M6 的生产发布门禁状态不因本验证改变。

## 5. 验证

- 第二 Domain Dispatcher、契约拒绝、共享预算、共享 Guardrail、Manifest/Registry
  一致性和应用非用户启用测试通过；
- 内核反向依赖与基础设施复制静态门禁通过；
- Python 全量回归通过（最终数量以本次执行输出为准）。
