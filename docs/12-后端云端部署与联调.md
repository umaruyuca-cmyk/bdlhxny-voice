# StockWise Backend 云端部署与联调

云端部署已经统一改为 Spring Boot `prod` Profile。

具体配置和命令请直接查看：

[15-云端配置运维.md](15-云端配置运维.md)

运维 AI 只需要执行：

```bash
docker compose -f deploy/docker-compose.cloud.yml up -d --build
```

配置修改位置：

```text
stockwise-backend/src/main/resources/application-prod.yml
```

不再使用 `.env.cloud`、`--env-file` 或外置 `application-secrets.yml`。
