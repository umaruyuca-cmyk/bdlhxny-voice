业务模块

FRONTEND

Runtime Console

首页、工作站、文档与 Skill 试用入口。浏览器只访问同源 /api/。

KERNEL

Python Orchestrator

认知编排、Domain 调度、Capability 网关、Guardrail、SSE 与 Pause/Resume。

DOMAIN

Finance Runtime

金融 Skill 宿主：校验请求、选 Skill、收集 Observation、组装领域结果。

DATA

Java Data Plane

认证、用户事实、会话/运行索引、任务与 Registry；Orchestrator 不直连业务库。

SKILL

Stock Skill

stock-research、portfolio-health、suitability-evaluation 等确定性金融计算。

SKILL

DeepSearch

Web Search Adapter：新闻/网页/舆情结构化检索，失败可降级。

模块边界

模块负责不负责
Cognitive Orchestrator选行动、追问、调用 Domain直连原始工具或供应商
Finance Runtime金融 Skill 与证据组装最终聊天文案
Stock / DeepSearch确定性计算 / 外部证据代替模型下结论
Java Data Plane身份、用户事实、持久化领域研判逻辑

整体架构

唯一产品路径：Cognitive → Domain Dispatcher → Finance Runtime → Skill / Capability → Observation → SSE。

Nginx / API Gateway → Python FastAPI（Cognitive Orchestrator） → Domain Dispatcher → Finance Runtime（Skill 宿主） → Stock Skill / DeepSearch / MCP / Java Data API → Observation / Evidence → Communication Plan → SSE / JSON

生产单元

单元角色
NginxTLS、路由、SSE、限流
Python Analysis通用编排内核 + finance 域
Java Data Plane认证、用户事实、状态持久化
PostgreSQL业务 / runtime / registry / memory schema
MCP / Web Search / LLM外部数据、证据补充、理解与表达
边界：公网只暴露 Nginx。Python、Java、搜索、数据库与消息组件走内网，不直接对公网监听。

请求链路

前端稳定只传 sessionId + message，身份走 JWT。编排路径固定为 cognitive_finance。

用户问题 → 识别研究对象与意图 → Cognitive 选择行动（RESPOND / ASK_USER / INVOKE_DOMAIN） → Finance Runtime 选择 Skill → Capability 拉取数据并转为 Observation → Stock Skill / DeepSearch 执行 → 校验完整性、时间与来源 → 模型解释（必要时付费研判） → 结论 + 依据 + 风险 + 数据时间
