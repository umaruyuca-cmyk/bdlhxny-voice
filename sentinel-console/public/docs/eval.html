评测的三种能力

评测不问「回答像不像人」，只测三种可以机械判定的能力。每种能力对应明确的判定口径与系统防线，数字全部由代码断言产生。

能力一：工具选择

项说明
测什么给定一句话，Agent 是否调用、且仅调用正确的工具（集合相等）
怎么测每题携带 expected_tools 金标；成功执行集 == 期望集记为通过
防线G1 可见性校验（装载集合防幻觉工具名）+ scoped 场景装载（缩小选择面）+ search 检索装载

能力二：幻觉抑制

项说明
测什么幻觉工具率（调用目录外工具名）+ 数字幻觉率（答案中的非平凡数字必须来自 Observation）
怎么测NumberGroundingCheck 对答案数字做接地断言；工具 Observation 是唯一事实源
防线G1 可见性 + Output Guardrail（数字接地与 C-1/C-2 合规复核，修正后输出）

能力三：权限与合规拦截

项说明
测什么越权泄漏（游客调用需登录的工具）+ 交易语义（C-1）+ 适当性结论（C-2）
怎么测游客身份题断言 absent_tools 未被执行；答案过 C-1 / C-2 检查
防线G3 身份与场景校验 + 交易工具物理不在目录（红线物理化）+ forbidden 快路径

判官说明

同一题库 × 三种架构 × 每题 N 次 → 机械判官（集合相等 / 数字接地 / 审计码断言） → 工具选择准确率 / 幻觉率 / 泄漏率 / 轮次 / token → 报告归档 docs/eval/
无 LLM 判官：所有指标由代码断言产生，可复跑、可回归；改一版提示词或换一个模型，同一题库重跑即可对比。
